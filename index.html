📲 How to Install TradeLog
📱 iPhone & iPad — Safari
1. Make sure you are viewing this page in Safari
2. Tap the Share button ⎙ at the bottom of Safari
3. Scroll down and tap "Add to Home Screen"
4. Tap Add — the TradeLog icon appears on your home screen
5. Open it from the home screen — it runs like a native app, fully offline ✓
💻 MacBook — Safari
1. Open this file in Safari
2. In the menu bar choose File → Add to Dock…
3. Click Add — TradeLog appears in your Dock
💻 MacBook / Windows — Chrome
1. Open this file in Chrome
2. Click the ⊕ install icon at the right end of the address bar
3. Click Install
🔄 Sync Mac ↔ iPhone
Tap ⬆ Export to download a JSON backup, then ⬇ Import on your other device. All your data transfers instantly.
⚠️ Important for iPhone
You must open this .html file in Safari first — you cannot run it directly from the Files app. AirDrop it to your Mac, open in Safari, then follow the steps above.
